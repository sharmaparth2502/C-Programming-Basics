# Geometry and Algebra

This folder contains simple C programs based on basic geometry and algebra concepts.

## Programs

1. Area of a Triangle using Heron's Formula
2. Distance Between Two Points
3. Midpoint of a Line Segment
4. Slope of a Line
5. Distance of a Point from a Line
6. Center and Radius of a Circle
7. Intersection of Two Lines
8. Angle of a Triangle using the Cosine Rule
9. Perimeter and Area of a Circle
10. Chord Length of a Circle

## Concepts Used

* Variables and data types
* User input and output
* Arithmetic operators
* Mathematical formulas
* `sqrt()`
* `acos()`
* Type conversion
* Basic geometry and algebra calculations

These programs are written for learning and practice.
