# Number and Digit Operations

This folder contains simple C programs for practicing number manipulation, digit operations, loops, and basic problem-solving.

## Programs

1. Sum of Last Digits
2. Sum of Second Last Digits
3. Sum of Numbers After Deleting the Last Digit
4. Sum of Numbers After Deleting the Second Last Digit
5. Sum of Products of the Last Two Digits
6. Sum After Exchanging the Last Two Digits
7. Find the Last Even Number
8. Weighted Sum of Numbers
9. Sum of Odd Numbers
10. Count the Number of Odd Numbers

## Concepts Used

* Variables and data types
* User input and output
* `for` loops
* Conditional statements
* Modulus operator `%`
* Integer division
* Digit extraction
* Number manipulation
* Basic arithmetic and logical operations

These programs are written for learning and practice.
